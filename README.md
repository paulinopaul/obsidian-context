---

## 📌 Problem Solved

AI coding agents (Antigravity, OpenCode, Claude Code, etc.) operate with volatile context that disappears once a task finishes. `obsidian-context` enables:

1. **Structured Project Knowledge Retention**: Captures technical decisions, libraries used, architectural trade-offs, and critical chat instructions upon completing tasks.
2. **Obsidian Graph View Exploration**: Automatically links project notes to centralized hub notes in `Technologies/[[Technology]]`, generating a visual knowledge graph across all your repositories.
3. **Tech Stack Analytics & Recommendations**: Analyzes historical usage to determine which libraries are most frequently used for specific domains (`web`, `cli`, `ai`, `networking`) and queries the user whether to reuse the proven stack or adopt a new one.
4. **Lightweight Local Embeddings (Zero PyTorch/CUDA)**: Powered by ChromaDB's `DefaultEmbeddingFunction` via native `ONNXRuntime` (`all-MiniLM-L6-v2`, 384 dimensions), eliminating the heavy ~2 GB footprint of `sentence-transformers`.
5. **Clean Vault Isolation**: All generated notes, technologies, and vector databases reside within an isolated `obsidian-context/` directory in your vault, preventing any clutter in your personal notes.
6. **Bilingual Note Output (EN/ES)**: Automatically generates notes in English or Spanish depending on user interaction and confirmation.

## 📂 Vault Setup & Directory Layout

> [!IMPORTANT]
> **Dedicated Vault Folder Required:**
> Create a dedicated folder named `obsidian-context` inside your Obsidian vault and specify your vault's path inside the skill's `config.json`. This ensures that all projects, technologies, and vector stores generated by AI agents are organized in a clean, self-contained workspace.

```
Your-Obsidian-Vault/
└── obsidian-context/                 <-- Dedicated folder inside your Obsidian Vault
    ├── Projects/                     <-- Completed project summaries ([[tech]] links)
    ├── Technologies/                 <-- Hub notes for Obsidian Graph View
    ├── Strategies/                   <-- Architectural patterns and practices
    └── chroma_storage/               <-- Local ChromaDB vector database (ONNX)
```

## 🤖 Universal Agent Directive (System Prompt Snippet)

You don't need any complex personal rules. Simply add the following snippet to your agent's system prompt or global rules file (such as `AGENTS.md`, `CLAUDE.md`, or `GEMINI.md`):

```markdown
### Memory & Knowledge Governance (obsidian-context)
When the `obsidian-context` skill is available:
1. **On Task Initiation:**
   Proactively ask the user whether to perform a context review:
   - English: "I detected the `obsidian-context` skill. Would you like to review historical context and recommended tech stack for this task, or would you prefer to skip this review?"
   - Spanish: "He detectado la skill `obsidian-context`. ¿Deseas hacer una revisión del contexto histórico y stack tecnológico recomendado para este trabajo, o prefieres omitir la revisión?"
   If approved, execute `scripts/tech_analytics.py --domain <domain>` or `scripts/search_context.py`.
2. **On Task Completion:**
   Before persisting, ask the user their preferred language for the notes:
   - English: "Would you like the technical summary and project notes saved in English or Spanish?"
   - Spanish: "¿Deseas que el resumen técnico y las notas del proyecto se guarden en español o prefieres en inglés?"
   Then execute `scripts/save_knowledge.py --lang <en|es>` followed by `scripts/sync_vault.py`.
```

## 🚀 Installation & Quick Start

### 1. Clone into Agent Skills Directory
```bash
# Standard directory for global Agent Skills
cd ~/.agents/skills
git clone https://github.com/<your-username>/obsidian-context.git
cd obsidian-context
```

### 2. Configure Your Vault Path in the Skill
Copy `config.example.json` to `config.json` and adjust your vault path:

```bash
cp config.example.json config.json
```

```json
{
  "vault_path": "/path/to/your/ObsidianVault",
  "context_folder": "obsidian-context",
  "projects_dir": "Projects",
  "technologies_dir": "Technologies",
  "strategies_dir": "Strategies",
  "chroma_dir": "chroma_storage",
  "default_language": "en"
}
```

### 3. Install Dependencies
```bash
pip install chromadb onnxruntime mcp
```

### 4. Create the Vault Directory & Initial Sync
```bash
# Create the isolated folder in your vault
mkdir -p "/path/to/your/ObsidianVault/obsidian-context"

# Initial indexation of existing notes
python3 scripts/sync_vault.py
```

## 💻 CLI Commands Reference

### Analyze Most Used Technologies
```bash
python3 scripts/tech_analytics.py --top 10 --lang en
```

### Get Recommendations for a Specific Domain
```bash
python3 scripts/tech_analytics.py --domain backend-rag --lang en
```

### Save Project Knowledge (Bilingual Support)
```bash
# Save in English
python3 scripts/save_knowledge.py \
  --name "Network Analyzer" \
  --domain "networking" \
  --techs "Python" "Scapy" "FastAPI" \
  --strategies "TDD" "Clean-Architecture" \
  --decisions "Adopted Scapy for packet crafting over raw sockets" \
  --instructions "Verify sandbox network permissions before sniffing" \
  --code "def capture(): pass" \
  --lang en

# Save in Spanish
python3 scripts/save_knowledge.py \
  --name "Analizador de Red" \
  --domain "networking" \
  --techs "Python" "Scapy" "FastAPI" \
  --strategies "TDD" "Clean-Architecture" \
  --decisions "Adopción de Scapy para captura de tramas" \
  --instructions "Validar permisos en sandbox" \
  --code "def capture(): pass" \
  --lang es
```

### Sync Vault to Local ChromaDB
```bash
python3 scripts/sync_vault.py
```

### Semantic Search Across Historical Knowledge
```bash
python3 scripts/search_context.py --query "persistence strategies in obsidian"
```
